برای نگهداری چند مقدار هم‌نوع، ابتدا مشخص کنید عناصر را با **اندیس** پیدا می‌کنید یا با **کلید**. آرایه و اسلایس برای دنباله‌های ترتیبی مناسب‌اند و مپ داده را به یک کلید وصل می‌کند. با `bufio` می‌توانید ورودی متنی را بخوانید و با تقسیم پردازش به توابع کوچک، هر بخش منطق را جداگانه به کار ببرید.

## آرایه (Array)

آرایه تعدادی عنصر هم‌نوع با طول ثابت دارد. طول بخشی از نوع است، بنابراین `[3]int` و `[4]int` دو نوع متفاوت‌اند. در `var scores [3]int` هر عنصر با مقدار صفر `int` شروع می‌شود. برای مقداردهی اولیه از `[3]int{18, 16, 20}` استفاده کنید. در `[...]int{18, 16, 20}` کامپایلر طول را از روی عناصر تعیین می‌کند.

اندیس‌ها از صفر شروع می‌شوند و آخرین اندیس معتبر `len(scores)-1` است. آرایه در انتساب و هنگام ارسال به تابع **به‌صورت مقدار کپی می‌شود**.

```go
scores := [...]int{18, 16, 20}
updated := scores
updated[0] = 19

fmt.Println(scores[0], updated[0]) // 18 19
```

برای پیمایش آرایه یا اسلایس، شکل مناسب `range` را انتخاب کنید.

- `for i, value := range scores` اندیس و مقدار را می‌دهد.
- `for _, value := range scores` فقط مقدار را نگه می‌دارد.
- `for i := range scores` فقط اندیس را می‌دهد. برای تغییر عنصر اصلی از `scores[i]` استفاده کنید.

اگر لازم است شمارنده را خودتان کنترل کنید، از `for i := 0; i < len(scores); i++` استفاده کنید. آرایهٔ چندبعدی هم آرایه‌ای از آرایه‌هاست. برای نمونه، `var matrix [2][3]int` دو ردیف سه‌عضوی دارد و `matrix[0][1]` عنصر دوم ردیف اول است. عناصر هر آرایه پشت‌سرهم در حافظه‌اند و دسترسی با اندیس زمان ثابت `O(1)` دارد. تخصیص روی پشته (Stack) یا هیپ (Heap) را کامپایلر بر اساس نحوهٔ استفاده تعیین می‌کند.

## اسلایس (Slice)

اسلایس نمایی با طول متغیر از یک **آرایهٔ زیرین** (Underlying Array) است. هدر اسلایس (Slice Header) به محل شروع عناصر اشاره می‌کند و طول و ظرفیت را نگه می‌دارد. `len(s)` تعداد عناصر فعلی و `cap(s)` تعداد خانه‌های قابل‌استفاده از آن نقطهٔ شروع در آرایهٔ زیرین است. با ارسال اسلایس به تابع، هدر کپی می‌شود و دسترسی به عناصر آرایهٔ زیرین مشترک می‌ماند.

| روش ساخت | نتیجه |
| --- | --- |
| <bdi dir="ltr"><code>[]int{10, 20}</code></bdi> | دو عنصر با مقدار اولیه |
| <bdi dir="ltr"><code>make([]int, 3)</code></bdi> | طول و ظرفیت ۳، با سه عنصر صفر |
| <bdi dir="ltr"><code>make([]int, 0, 3)</code></bdi> | طول صفر و ظرفیت ۳، آمادهٔ افزودن عناصر |
| <bdi dir="ltr"><code>var s []int</code></bdi> | اسلایس `nil` با طول و ظرفیت صفر که می‌توان به آن `append` کرد |

در `values[low:high]`، اندیس `low` در برش هست و `high` مرز بیرونی بازه است. `values[:2]` دو عنصر اول، `values[2:]` عناصر از اندیس ۲ تا انتها و `values[:]` همهٔ عناصر فعلی را در بر می‌گیرد.

نتیجهٔ `append` را دوباره به متغیر اسلایس اختصاص دهید. تا وقتی ظرفیت کافی است، `append` از آرایهٔ زیرین موجود استفاده می‌کند. وقتی جا کافی نباشد، آرایهٔ جدیدی می‌سازد و عناصر فعلی را در آن کپی می‌کند.

```go
scores := [3]int{10, 20, 30}
window := scores[1:] // len=2, cap=2
window[0] = 25
fmt.Println(scores) // [10 25 30]

window = append(window, 40) // Grow past capacity.
window[0] = 99
fmt.Println(scores) // [10 25 30]
fmt.Println(window) // [99 30 40]
```

`append(make([]int, 3), 5)` مقدار `[0 0 0 5]` را می‌سازد، چون سه عنصر اولیه بخشی از طول‌اند. برای تغییر یکی از آن‌ها از اندیس استفاده کنید. برای افزودن همهٔ عناصر یک اسلایس دیگر، بنویسید `values = append(values, more...)`. برای لیست‌هایی که اندازه‌شان در زمان اجرا مشخص یا تغییر می‌کند، اسلایس انتخاب معمول است.

## مپ (Map)

مپ با نوع `map[K]V` مجموعه‌ای از کلیدهای یکتا از نوع `K` را به مقادیر نوع `V` نگاشت می‌کند. برای جست‌وجوی اطلاعات با نام یا شناسه، شمارش و نگهداری داده‌های کلید–مقدار از مپ استفاده کنید. مپ با هش‌کردن کلید محدودهٔ جست‌وجو را کوچک می‌کند. عملیات معمول روی کلید زمان متوسط `O(1)` دارد.

مپ خالی قابل‌نوشتن را با `make(map[string]int)` یا با یک literal مثل `map[string]int{"pens": 0}` بسازید. مقدار صفر یک مپ `nil` است. خواندن از آن مقدار صفرِ نوع مقدار را برمی‌گرداند و نوشتن در آن باعث `panic` می‌شود.

```go
stock := map[string]int{"pens": 0}
stock["notebooks"] = 12

count, ok := stock["pens"]
fmt.Println(count, ok) // 0 true

count, ok = stock["markers"]
fmt.Println(count, ok) // 0 false

delete(stock, "notebooks")
fmt.Println(len(stock)) // 1
```

الگوی **Comma OK**، یعنی `value, ok := m[key]`، کمک می‌کند کلید غایب را از کلید موجود با مقدار صفر تشخیص دهید. همان انتساب `m[key] = value` برای درج و به‌روزرسانی به کار می‌رود. برای شمارش در یک مپ `map[string]int` که با `make` یا literal ساخته شده، `counts[name]++` مقدار کلید تازه را از صفر به یک می‌رساند. حذف کلید غایب اثری ندارد. `for key, value := range m` کلید و مقدار هر عضو را می‌دهد و ترتیب پیمایش تضمین نمی‌شود.

نوع کلید باید قابل‌مقایسه (Comparable) باشد. عدد، رشته، `bool`، اشاره‌گر و کانال قابل‌استفاده‌اند. آرایه‌ها و استراکت‌ها وقتی مجازند که تمام عناصر یا فیلدهایشان قابل‌مقایسه باشند. در کلید از نوع Interface، مقدار واقعی داخل آن هم باید قابل‌مقایسه باشد. اسلایس، مپ و تابع نوع کلید معتبر نیستند.

## ورودی با `bufio`

بافر (Buffer) بخشی از دادهٔ ورودی را موقت نگه می‌دارد تا خواندن قطعه‌های کوچک به مراجعهٔ مکرر به منبع نیاز نداشته باشد. برای خط‌هایی که داخلشان فاصله دارند، مثل نام کامل یک مدرس، `Scanner` روش ساده‌ای است. `Text()` متن خط را بدون پایان خط می‌دهد. پس از اتمام حلقه، `Err()` را برای تشخیص خطا بررسی کنید.

```go
scanner := bufio.NewScanner(os.Stdin)
for scanner.Scan() {
	fmt.Println(scanner.Text())
}
if err := scanner.Err(); err != nil {
	fmt.Fprintln(os.Stderr, err)
}
```

اگر جداکنندهٔ دلخواه یا کنترل بیشتری روی خواندن می‌خواهید، از `Reader` استفاده کنید. `ReadString('\n')` خط را همراه جداکننده برمی‌گرداند، اگر جداکننده پیدا شده باشد. ممکن است آخرین خط بدون پایان خط همراه `io.EOF` برگردد. دادهٔ دریافت‌شده را در این حالت هم پردازش کنید.

```go
reader := bufio.NewReader(os.Stdin)
line, err := reader.ReadString('\n')
if err != nil && err != io.EOF {
	fmt.Fprintln(os.Stderr, err)
	return
}
if line != "" {
	fmt.Println(strings.TrimRight(line, "\r\n"))
}
```

`TrimRight` در این مثال فقط نویسه‌های پایان خط را از انتهای رشته برمی‌دارد و فاصله‌های داخل خط را حفظ می‌کند. برای خواندن توکن‌ها به‌صورت خط‌به‌خط یا کلمه‌به‌کلمه، `Scanner` مناسب است. `Reader` عملیات کنترل‌شده‌تری مثل `Peek` برای دیدن بایت‌های بعدی بدون خواندن آن‌ها فراهم می‌کند.

## توابع (Functions)

تابع با `func` تعریف می‌شود و یک کار مشخص را انجام می‌دهد. در `func add(a, b int) int`، متغیرهای `a` و `b` پارامترند و `int` بعد از پرانتز نوع خروجی است. مقادیر `2` و `3` در فراخوانی `add(2, 3)` آرگومان‌اند. پارامترهای متوالی هم‌نوع می‌توانند نوع را مشترک بنویسند. تابعی که خروجی ندارد نوع بازگشتی هم ندارد.

در کنار نتیجه می‌توانید یک مقدار دیگر مثل وضعیت موفقیت یا `error` برگردانید. این تابع برای مجموعهٔ بدون عضو میانگین تعریف نمی‌کند و وضعیت را به فراخواننده گزارش می‌دهد.

```go
func average(sum, count int) (float64, bool) {
	if count == 0 {
		return 0, false
	}
	return float64(sum) / float64(count), true
}
```

در `value, ok := average(15, 2)`، نتیجه `7.5` است و `ok` مقدار `true` دارد. فراخواننده باید پیش از استفاده از نتیجه، وضعیت را بررسی کند. می‌توانید برای خروجی‌ها نام بگذارید، مثل `(area int, perimeter int)`. در این حالت `return` خالی (Naked Return) مقادیر فعلی آن نام‌ها را برمی‌گرداند. در تابع طولانی، `return area, perimeter` مسیر خروجی را خواناتر می‌کند.

پارامتر Variadic در انتهای فهرست پارامترها قرار می‌گیرد و تعداد متغیری آرگومان می‌پذیرد. داخل تابع، آن را مثل یک اسلایس پیمایش می‌کنید.

```go
func sum(values ...int) int {
	total := 0
	for _, value := range values {
		total += value
	}
	return total
}
```

`sum(1, 2, 3)` مقدار `6` می‌دهد. اگر داده‌ها در اسلایس `values` هستند، با `sum(values...)` عناصر را به تابع پاس بدهید.

## تابع به‌عنوان مقدار و Closure

در Go تابع یک مقدار درجه‌یک (First-Class Value) است. می‌توانید آن را در متغیر نگه دارید، به تابعی دیگر بدهید یا از یک تابع برگردانید. تابع ناشناس (Anonymous Function) نام ندارد و می‌توان آن را بلافاصله با `()` فراخواند، مثل `func() { fmt.Println("Ready") }()`.

```go
func apply(n int, op func(int) int) int {
	return op(n)
}

func multiplier(factor int) func(int) int {
	return func(n int) int {
		return n * factor
	}
}
```

`double := multiplier(2)` یک تابع برمی‌گرداند که به `factor` دسترسی دارد، حتی بعد از پایان اجرای `multiplier`. به این تابع همراه با متغیرهای محیطش **Closure** می‌گوییم. `apply(5, double)` مقدار `10` را می‌دهد. تابعی مانند `apply` یا `multiplier` که تابع می‌گیرد یا برمی‌گرداند، تابع مرتبه‌بالا (Higher-Order Function) است.

## اجرای کار هنگام خروج با `defer`

`defer` اجرای یک فراخوانی را تا خروج از تابع فعلی به تعویق می‌اندازد. برای آزادسازی منابع، آن را بلافاصله بعد از به‌دست‌آوردن موفق منبع بنویسید، مثل `defer file.Close()` پس از باز شدن فایل. چند `defer` به‌ترتیب معکوس اجرا می‌شوند (LIFO).

```go
func finish() {
	defer fmt.Println("first defer")
	defer fmt.Println("second defer")
	fmt.Println("work")
}
```

با فراخوانی `finish()` ابتدا `work`، بعد `second defer` و در آخر `first defer` چاپ می‌شود.
