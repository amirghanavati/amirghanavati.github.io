title: آشنایی با زبان Go

در این فصل یک برنامهٔ خط فرمان Go می‌سازیم و با ابزارهای پایهٔ آن برای ذخیرهٔ داده، تصمیم‌گیری، تکرار و خواندن ورودی آشنا می‌شویم. برای اجرای مثال‌ها، Go باید روی سیستم نصب باشد.

## اولین برنامه

در یک پوشهٔ خالی، دستور `go mod init hello` را اجرا کنید. ماژول (Module) مجموعه‌ای از پکیج‌های مرتبط است که با هم نسخه‌بندی می‌شوند. این دستور فایل `go.mod` را می‌سازد. مسیر ماژول، نسخهٔ Go و وابستگی‌های پروژه در این فایل ثبت می‌شوند.

این کد را در فایل `main.go` ذخیره کنید. `package main` پکیج برنامهٔ اجرایی است و اجرای برنامه از تابع `main` شروع می‌شود. پکیج استاندارد `fmt` با `import` در دسترس قرار می‌گیرد.

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```

| دستور | کاربرد |
| --- | --- |
| `go run main.go` | کد را کامپایل و اجرا می‌کند. برای بررسی سریع مفید است و فایل اجرایی دائمی در پوشهٔ پروژه ایجاد نمی‌کند. |
| `go build` | در این ماژول فایل اجرایی `hello` را می‌سازد. روی Linux و macOS با `./hello` و در PowerShell با `.\hello.exe` اجرا می‌شود. |

تابع داخلی `println` بدون `import` برای مثال‌های ساده در دسترس است. برای خروجی کنسول و کنترل قالب از `fmt` استفاده کنید.

## متغیرها، ثابت‌ها و انواع داده

`var` متغیری با نوع مشخص تعریف می‌کند. اگر مقدار اولیه ندهید، Go **مقدار صفر** (Zero Value) آن نوع را قرار می‌دهد. با مقدار اولیه می‌توان نوع را به کامپایلر سپرد (Type Inference). شکل کوتاه `:=` فقط داخل تابع استفاده می‌شود. برای مقداری که در زمان کامپایل مشخص است و تغییر نمی‌کند، از `const` استفاده کنید.

```go
var earthWeight int // 0 تا پیش از مقداردهی
var name = "Helia"   // نوع string
earthWeight = 80
const gravityRatio = 0.3783
equivalentWeight := float64(earthWeight) * gravityRatio
fmt.Printf("%s: %.3f\n", name, equivalentWeight) // Helia: 30.264
```

می‌توانید چند متغیر هم‌نوع را در یک خط، مثل `var x, y int`، تعریف کنید. بلوک‌های `var (...)` و `const (...)` برای گروه‌بندی تعریف‌های مرتبط به کار می‌روند.

| نوع | کاربرد | مقدار صفر |
| --- | --- | --- |
| `int`، `int8` تا `int64` | اعداد صحیح علامت‌دار | `0` |
| `uint`، `uint8` تا `uint64` | اعداد صحیح نامنفی | `0` |
| `float32`، `float64` | اعداد اعشاری با دقت متفاوت | `0` |
| `bool` | `true` یا `false` برای شرط‌ها | `false` |
| `string` | دنبالهٔ تغییرناپذیر بایت‌ها که برای متن معمولاً به‌صورت UTF-8 تفسیر می‌شود | `""` |
| `byte` | نام مستعار `uint8`، مناسب کار با یک بایت، مانند `'A'` در ASCII | `0` |
| `rune` | نام مستعار `int32` برای یک کدپوینت Unicode، مانند `'ش'` | `0` |

عدد کنار نوع‌هایی مثل `int8` تعداد بیت‌ها را نشان می‌دهد و روی بازهٔ مقادیر اثر دارد. در رشتهٔ داخل دابل‌کوتیشن، `\n` به خط جدید تبدیل می‌شود. رشتهٔ خام (Raw String) میان بک‌تیک نوشته می‌شود، می‌تواند چندخطی باشد و `\n` را به همان شکل نگه می‌دارد.

Go نوع‌دهی ایستا دارد. برای انجام محاسبه بین یک متغیر `int` و یک مقدار `float64`، نوع‌ها را صریحاً همسان کنید، همان‌طور که در مثال وزن انجام شد. هنگام تبدیل به نوع صحیح، بخش اعشاری حذف می‌شود. برای تبدیل متن به عدد، پکیج استاندارد `strconv` ابزار تبدیل را فراهم می‌کند.

## کنترل جریان

### شرط‌ها

`if` یک شرط بولی را می‌سنجد و بدنه‌اش همیشه آکولاد دارد. در زنجیرهٔ `if / else if / else`، اولین شرط برقرار مسیر اجرا را تعیین می‌کند. می‌توانید یک دستور کوتاه پیش از شرط بنویسید. متغیری که آنجا با `:=` تعریف می‌شود، در همان `if` و شاخه‌های `else` آن در دسترس است.

```go
if num := 9; num < 0 {
	fmt.Println("Negative")
} else if num < 10 {
	fmt.Println("One digit")
}
```

از `switch value` برای مقایسهٔ یک مقدار با چند گزینه استفاده کنید. برای حالت‌هایی با رفتار یکسان، چند مقدار را در یک شاخه بنویسید، مثل `case "+", "-", "*", "/":`. `default` اختیاری است و وقتی اجرا می‌شود که هیچ گزینه‌ای مطابق نباشد. Go بعد از اجرای یک `case` به‌طور خودکار از `switch` خارج می‌شود. `fallthrough` بدنهٔ شاخهٔ بعدی را بدون بررسی شرط آن اجرا می‌کند. در `switch` بدون عبارت، شرط‌ها به‌ترتیب بررسی می‌شوند و اولین شاخهٔ درست اجرا می‌شود.

### حلقه‌ها

| شکل حلقه | زمان استفاده |
| --- | --- |
| `for i := 1; i <= 5; i++` | مقداردهی اولیه یک بار اجرا می‌شود. شرط پیش از هر دور و دستور به‌روزرسانی پس از هر دور اجرا می‌شوند. |
| `for n > 0` | برای تکرار تا وقتی یک شرط برقرار است. تغییر مقدار `n` را در بدنه انجام دهید. |
| `for { ... }` | برای تکرار مداوم. مسیر خروج را مشخص کنید، مثل فرمان `exit` در یک برنامهٔ خط فرمان. |

`break` حلقه را تمام می‌کند. `continue` بقیهٔ دور فعلی را کنار می‌گذارد. این مثال اعداد فرد کوچک‌تر از ۸ را چاپ می‌کند.

```go
for i := 1; i < 15; i++ {
	if i >= 8 {
		break
	}
	if i%2 == 0 {
		continue
	}
	fmt.Println(i)
}
```

## پکیج‌ها، نام‌گذاری و دامنه

پکیج (Package) گروهی از فایل‌های `.go` مرتبط در یک پوشه است. پکیج‌های دیگر را با `import` وارد می‌کنید و با نام پکیج به اعضای صادرشدهٔ آن دسترسی پیدا می‌کنید، مثل `fmt.Println`. چند import را می‌توان در یک بلوک `import (...)` نوشت.

- برای نام‌های چندکلمه‌ای صادرنشده (Unexported) از camelCase استفاده کنید، مثل `defaultHost`. عضو سطح پکیج با حرف اول بزرگ صادر می‌شود (Exported) و از پکیج‌های دیگر قابل دسترسی است، مثل `MaxConnections`.
- متغیر محلی و import بلااستفاده خطای کامپایل می‌دهند. شناسهٔ خالی (Blank Identifier) یعنی `_` یک مقدار را عمداً نادیده می‌گیرد. مثلاً در `_, err := fmt.Scan(&name)` تعداد مقادیر خوانده‌شده را کنار می‌گذارید و خطا را نگه می‌دارید. پیشوند `_` در یک import برای اجرای اثر جانبی پکیج، مانند مقداردهی اولیه، به کار می‌رود.
- سایه‌اندازی (Shadowing) وقتی رخ می‌دهد که متغیر تازه‌ای با نام یک متغیر بیرونی در بلوک داخلی تعریف شود. اگر بیرون بلوک `level := "Outer"` و داخل آن `level := "Inner"` بنویسید، مقدار بیرونی پس از بلوک همچنان `"Outer"` است. برای تغییر متغیر موجود از `=` استفاده کنید.

## ورودی و خروجی با `fmt`

| تابع | رفتار |
| --- | --- |
| `Println` | آرگومان‌ها را با فاصله چاپ می‌کند و در انتها به خط بعد می‌رود. |
| `Print` | به‌طور خودکار خط جدید اضافه نمی‌کند. برای نوشتن پیام ورودی روی همان خط مفید است. اگر بین دو رشته فاصله می‌خواهید، آن را در متن قرار دهید. |
| `Printf` | طبق یک رشتهٔ قالب چاپ می‌کند. برای رفتن به خط بعد، `\n` را در قالب بنویسید. |
| `Sprintf` | متن قالب‌بندی‌شده را به‌صورت `string` برمی‌گرداند تا بعداً از آن استفاده کنید. |
| `Scan` | ورودی را بر اساس فاصله، تب یا خط جدید به مقادیر جدا می‌کند. یک مقصد `string` معمولاً یک کلمه را دریافت می‌کند. |
| `Scanln` | ورودی را به مقادیر جدا می‌کند و در خط جدید متوقف می‌شود. |
| `Scanf` | ورودی را با الگوی مشخص تطبیق می‌دهد، مثل خواندن سه عدد جداشده با خط تیره. |

### فعل‌های قالب‌بندی (Format Verbs)

| فعل | کاربرد |
| --- | --- |
| `%v`، `%T` | نمایش مقدار با قالب پیش‌فرض یا نمایش نوع آن |
| `%d`، `%b`، `%o`، `%x`، `%X` | نمایش عدد صحیح در مبناهای ۱۰، ۲، ۸ و ۱۶ |
| `%f`، `%.2f` | نمایش عدد اعشاری، با دو رقم بعد از ممیز در حالت دوم |
| `%s`، `%q`، `%c` | نمایش رشته، رشتهٔ نقل‌قول‌شده یا کاراکتر |
| `%t`، `%p` | نمایش مقدار بولی یا آدرس اشاره‌گر |

### بررسی ورودی

به توابع خواندن، آدرس متغیر مقصد را با `&` بدهید تا مقدار خوانده‌شده را در آن بنویسند. این توابع تعداد مقادیر خوانده‌شده و یک خطا برمی‌گردانند. قبل از استفاده از ورودی، `err` را بررسی کنید. مثال زیر ساختار تاریخ را می‌خواند. اعتبار روز و ماه باید جداگانه بررسی شود.

```go
var year, month, day int
if _, err := fmt.Scanf("%d-%d-%d", &year, &month, &day); err != nil {
	fmt.Println("Use year-month-day")
	return
}
fmt.Printf("Year=%d, Month=%d, Day=%d\n", year, month, day)
```

در `Scanf` جداکننده‌ها و فاصله‌های ورودی اهمیت دارند. مثلاً `2025/11/08` با الگوی خط‌تیره تطبیق ندارد. برای خواندن از منبعی دیگر یا نوشتن در مقصدی دیگر، `Fscanf` و `Fprintf` به‌کار می‌روند.

## تمرین‌های این فصل

- **وزن معادل روی سیاره**. وزن زمین را به‌صورت `int` بگیرید، آن را به `float64` تبدیل کنید و در ثابت نسبت جاذبه ضرب کنید. برای وزن ۸۰ و نسبت ۰٫۳۷۸۳، نتیجه ۳۰٫۲۶۴ است.
- **شرط‌های وام در تمرین**. به‌ترتیب سن کمتر از ۱۸، سابقهٔ اعتباری نامطلوب و درآمد کمتر از ۱۰ میلیون تومان را بررسی کنید. اولین مورد برقرار دلیل رد است و در صورت عبور از هر سه شرط، `Loan approved` چاپ می‌شود.
- **بازی Hop**. از ۱ تا `q` بشمارید. در حالت عادی خود عدد را چاپ کنید. با فرض `p > 0`، برای هر مضربِ `p`، عبارت `Hop` را به تعداد خارج‌قسمت `i / p` در یک خط چاپ کنید. برای `p = 3` عدد ۶ به `Hop Hop` تبدیل می‌شود.
- **ماشین‌حساب خط فرمان**. در هر دور عملگر را بخوانید. برای `+`، `-`، `*` و `/` دو مقدار `float64` بگیرید و نتیجه را با قالب `Result: %.4f` چاپ کنید. پس از `Unknown command` یا `Error: Invalid mixture` در تقسیم بر صفر، به دور بعد بروید. فرمان `exit` پیش از خواندن دو عدد، `Lab console terminated` را چاپ می‌کند و برنامه را می‌بندد.
